# kabacal

**This branch (`main`) is intentionally empty except for a private placeholder.**

GitHub Pages serves this branch, and Pages serves *every* file in it — so anything committed
here (source, docs, rules, test fixtures) becomes publicly readable on the internet. The
public site was taken down on 2026-09-20 by decision of the repository owner.

**Everything real lives on the `app` branch:** the application (`index.html`), the agent
instructions (`AGENTS.md`, `CLAUDE.md`, `STATUS.md`), the rule book, the docs, the tooling and
the goldens.

Working here (human or AI agent):

```
git checkout app       # the real repository state; read AGENTS.md first
```

Do not restore files to `main` without an explicit new decision from the owner.
